# EMG两阶段运动分类系统

## 设计思路

受小组成员讨论启发，采用**两阶段分类器**替代直接三分类：

```
                    EMG信号
                       │
              ┌────────┴────────┐
              │   第一层分类器    │
              │ (推肩 vs 弯举类) │
              └────────┬────────┘
                       │
         ┌─────────────┴─────────────┐
         │                           │
    预测为推肩                    预测为弯举/锤式弯举
         │                           │
         ▼                           ▼
    [推肩: 3]              ┌────────┴────────┐
                           │   第二层分类器   │
                           │ (弯举 vs 锤式)  │
                           └────────┬────────┘
                                    │
                          ┌────────┴────────┐
                          │                 │
                       [弯举]          [锤式弯举]
                        (1)               (2)
```

## 特征选择

### 第一层：推肩 vs 弯举/锤式弯举

**选用特征：**
1. **肱三头肌RMS** - 推肩主要激活肱三头肌
2. **RMS比值（二头/三头）** - 推肩时三头主导，比值低
3. **能量比值（二头/三头）** - 同上

**设计理由：**
- 推肩是**推**的动作，主要由肱三头肌发力
- 弯举和锤式弯举都是**拉**的动作，主要由肱二头肌发力
- 肱三头肌的激活程度和二三头的比值是天然的区分特征

### 第二层：弯举 vs 锤式弯举

**选用特征：**
1. **肱二头肌RMS** - 两种弯举都主要激活二头
2. **过零率(ZC)** - 两种动作的肌电波形略有不同
3. **斜率变化(SSC)** - 肌肉收缩模式有细微差异
4. **均值频率(MF)** - 频域特征辅助区分
5. **中位频率(MDF)** - 频域特征
6. **主频率(PF)** - 频域特征

**设计理由：**
- 弯举和锤式弯举的肌肉激活模式相似
- 需要更精细的波形和频域特征来区分
- 选择**6个特征**而非全部，避免过拟合

## 优势

1. **可解释性强** - 每个特征的选择都有生理学依据
2. **避免过拟合** - 每个分类器只学习2-3个关键特征
3. **准确率更稳定** - 分而治之，降低分类难度
4. **新意** - 两阶段分类比直接三分类更有创新性

## 文件结构

```
emg_classification_v2/
├── emg_two_stage_main.m       # 主程序（训练两阶段分类器）
├── emg_predict_two_stage.m   # 预测函数
├── emg_preprocess.m          # 预处理
├── emg_segment_simple.m      # 动作段检测
├── emg_feature_extract.m      # 特征提取
└── models/                   # 训练好的模型
    └── two_stage_model.mat
```

## 使用方法

### 1. 训练模型

```matlab
% 进入项目目录，直接运行
emg_two_stage_main
```

### 2. 预测盲测数据

```matlab
[prediction, confidence] = emg_predict_two_stage('/path/to/blind_test.mat');
```
